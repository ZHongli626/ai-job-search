# 香港高端人才通行证计划（高才通）B类申请清单

最后更新：2026-08-26

> 本清单根据香港入境事务处目前公布的高才通计划资料整理。提交前请再次核对官方网页，因为入境政策、文件要求和收费可能调整。

## 一、B类资格初步判断

B类的核心条件是：

1. 持有合资格大学颁授的学士学位；以及
2. 在紧接申请前五年内，累计至少三年毕业后的全职或自雇工作经验。

根据当前候选人资料：

- [X] 2015至2018年在南开大学取得 Finance 学士学位。南开大学目前列入高才通合资格大学综合名单。
- [X] 确认学士学位是否为正式、全日制学位，并准备毕业证书和完整成绩单。
- [ ] 确认学历认证方式，并取得第三方认证机构或颁授院校出具的可在线验证的学历认证文件。
- [ ] 核实2021-08-26至申请日之间是否能够证明累计至少三年的“毕业后全职或自雇工作经验”。博士阶段的研究/雇佣经历是否符合要求，不能仅凭“PhD candidate”身份判断，需以雇佣合同、雇主证明和入境处口径确认为准。
- [ ] 如三年工作经验无法证明，暂停递交B类申请，并咨询入境处是否应考虑其他类别或等待补足年限。

## 三、建议的准备顺序

### 阶段1：先确认是否真的满足B类

- [X] 列出过去五年内所有毕业后的工作/雇佣经历，按月份计算累计全职时间。
- [ ] 向Bielefeld University确认博士阶段的合同性质、工作时间、雇主和可出具的证明。
- [X] 确认申请日。B类的五年窗口按申请日前五年计算，不能用较早时期的经历替代窗口内经验。
- [X] 将每段经历对应到证据：合同、雇主证明、工资单、税务/社保记录。
- [ ] 如累计年限不足或经历性质不明确，先向香港入境处查询，不要提交可能无法证明资格的申请。

### 阶段2：准备学历材料

- [ ] 扫描南开大学学士学位毕业证书。
- [ ] 获取正式成绩单。
- [ ] 核对学位名称、姓名拼写、出生日期和护照信息是否一致。
- [ ] 申请学历认证，并记录认证机构、验证网址、账号或验证码等信息。
- [ ] 对非中文/英文材料安排合资格翻译及核证。

### 阶段3：准备身份和居留材料

- [ ] 扫描护照个人资料页。
- [ ] 检查护照有效期，并确认是否有可返回德国的有效居留许可。
- [ ] 准备德国居留证明，显示居留条件和期限。
- [ ] 准备近期电子证件照片。
- [ ] 如有香港身份证、旧护照或香港入境记录，按官方要求一并整理。

### 阶段4：网上提交

- [ ] 再次核对官方B类资格和文件清单。
- [ ] 将所有文件按清晰、易读的PDF或图片格式命名并分类。
- [ ] 填写网上申请表，确保所有日期和经历与证明文件一致。
- [ ] 上传文件并支付申请费。
- [ ] 下载/保存确认页面、申请编号、付款收据和所有上传文件。

## 四、提交后跟进

- 入境处在收到所有所需文件和申请费后，一般约需四星期处理；材料不完整时不会开始处理。
- 处理期间定期检查邮箱和申请状态，如收到补件要求，记录截止日期并一次性准备完整回复。
- 获批后按通知缴付签证签发费，再下载或列印电子签证。
- B类首次入境通常获准逗留24个月，实际结果以入境处批准为准。
- 如要延长逗留，应在现有逗留期限届满前三个月内申请，并尽量至少提前六星期提交；届时通常需要证明已在香港受聘并有稳定收入，或已在香港经营/参与业务。

## 五、当前最优先的三件事

1. **确认三年工作经验是否满足B类定义。** 重点核实博士阶段经历是否属于毕业后的全职工作，以及能否取得正式证明。
2. **确认南开大学学士学历认证路径。** 先准备毕业证和成绩单，再申请可在线验证的学历认证文件。
3. **核对护照与德国居留材料。** 由于目前居住在德国，准备能证明海外合法居留条件和期限的文件。
