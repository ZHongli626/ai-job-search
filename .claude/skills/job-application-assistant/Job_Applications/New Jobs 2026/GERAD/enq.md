# 想请教的 GERAD 博后经历

圆圆你好！我最近看到 GERAD 2027–2028 年的博后 fellowship，正在考虑申请。看到你在 HEC Montréal 和 GERAD 做博后，研究也涉及企业决策、不确定性和客户行为，想听听你的实际体验，主要有下面几个问题。你方便的时候聊聊就好，不用逐条回答。

1. **整体体验和研究氛围**：你在 GERAD 做博后的感受怎么样？平时大家交流、讨论和合作多吗？你觉得这里最有吸引力的地方是什么，有哪些入职前值得了解的情况？
2. **我的背景是否合适**：我主要做计算经济学、产业组织和基于主体的建模，研究企业决策、网络效应和消费者异质性，也有机器学习方面的研究。你觉得这样的背景在 GERAD 容易找到契合的合作方向吗？经济学背景的研究者通常需要补哪些运筹优化方面的方法？
3. **导师选择和联系**：你和 Jean-François Cordeau、Yossiri Adulyasak、Emma Frejinger 的合作是怎么建立起来的？这次 fellowship 要求两位 GERAD 正式成员共同指导，你觉得我可以先联系哪些老师？一般是先找一位讨论研究想法，再一起确定另一位，还是一开始就分别联系两位？
4. **研究自主性和日常安排**：博后的课题通常是延续自己的研究，还是主要参与导师已有的项目？共同指导在实际工作中怎么分工，多久交流一次？平时有没有教学、指导学生或企业合作方面的任务，工作节奏如何？
5. **申请经验**：不知道你当时是否通过这个 fellowship 入职？如果是，你觉得研究计划、论文成果和导师支持中，哪些最关键？如果走的是其他渠道，也想了解一下除了这个 competition，是否还有导师项目直接招博后的机会。
6. **资助期限和待遇**：公告写的是每份 fellowship 至少 75,000 加元，其中 GERAD 出 45,000，导师补至少 30,000，但我还不清楚这笔钱对应多长时间。按你了解的情况，合同一般签多久，后续续约或延长资助的机会怎么样？如果方便分享，大概的税后收入、医保福利，以及在蒙特利尔租房后的生活宽裕程度如何？
7. **工作地点和生活适应**：你平时主要在 GERAD 还是 HEC 办公？公告要求资助期间在 GERAD，实际对到岗、短期出差和参加会议是怎么安排的？日常科研和生活用英语是否方便，法语大概需要到什么程度？办理签证、入职和找房时，有没有特别需要提前准备的事？
8. **后续发展**：你觉得这段博后经历对之后找教职或去业界帮助大吗？导师和中心在论文发表、学术交流、求职推荐以及企业联系方面，通常能提供哪些支持？如果重新选择一次，你还会来吗？

谢谢！我最想先了解的是研究方向是否合适、导师怎么选，以及实际工作和生活的体验。后面如果确定申请，再向你请教具体材料。
