### Tools

#### Axure RP

官网：https://www.axure.com/

**产品简介：** Axure RP 是面向产品经理、UX 设计师和业务分析师的专业原型设计与需求沟通工具，适合在开发前将复杂业务逻辑转化为可操作、可验证的产品方案。它不仅可以绘制线框图和流程图，也能在无需编程的情况下制作接近真实产品体验的高保真交互原型。

**主要功能：**

- 使用事件、条件逻辑、变量和动态面板设计复杂交互；
- 制作表单、可排序或筛选的数据表格、自适应页面等数据驱动界面；
- 在同一项目中管理用户流程、线框图、需求说明和交互注释；
- 通过 Axure Cloud 分享原型、收集评审反馈，并向研发交付标注、资源和 CSS 信息。

**与我的背景及岗位的结合：** 我尚未将 Axure 列为已有熟练工具，因此申请材料中不应声称拥有实际项目经验。不过，我的计算经济学研究长期要求把复杂机制拆解为变量、条件、状态和反馈回路，这与 Axure 的条件逻辑和动态交互设计具有很强的可迁移性。针对字节跳动的财务 AI 产品，可以用 Axure 将报销、审批、预算控制或异常识别流程转化为可测试原型；再结合我的金融教育、财务系统接触经历以及 Python 数据分析能力，与财务用户澄清需求、定义产品指标，并向设计和研发团队准确表达业务规则。Axure 更适合承载逻辑复杂、需要深入验证的核心流程原型。

#### 墨刀（Modao）

官网：https://modao.cc/

**产品简介：** 墨刀是一体化的智能原型设计与产品研发协作平台，覆盖白板梳理、原型设计、UI/UX 设计、团队评审和研发交付等环节。其拖拽式组件、模板和在线协作能力强调快速上手，也支持通过 AI 生成多页面原型、PRD 和评审材料。

**主要功能：**

- 快速制作高保真交互原型，并通过链接或真机扫码进行演示和评审；
- 使用白板开展用户调研、竞品分析、用户旅程和业务流程梳理；
- 支持团队实时协作、素材与设计规范管理、切图标注及多级权限控制；
- 利用 AI 从文字需求或草图生成原型，并辅助生成 PRD、PPT 和评审方案；
- 支持 Sketch、Figma 文件迁入，以及部分设计稿到代码的交付流程。

**与我的背景及岗位的结合：** 我尚未将墨刀列为已有熟练工具，但其低门槛、在线协作和 AI 辅助功能与我的工作方式高度契合。我已使用 Microsoft AutoGen、LangChain 和 OpenAI API 构建 Agentic AI 研究工作流，也组织和参与过跨机构研究项目与学术活动，因此能够把需求拆解、AI 工作流设计和跨团队沟通经验迁移到墨刀中。针对该岗位，我可以用白板梳理全球财务用户、痛点和端到端流程，快速形成报销或审批类产品原型，通过在线评审收集反馈，并借助 AI 功能加速 PRD 和汇报材料的初稿制作。墨刀更适合快速共创、早期验证和高频迭代。

#### 两款工具在产品流程中的配合

墨刀和 Axure 并非简单替代关系。实际工作中，可先用墨刀白板完成用户访谈归纳、流程梳理和跨部门共创，并快速制作低至中保真原型；当关键财务流程涉及多角色权限、复杂审批条件、数据状态变化或异常处理时，再用 Axure 制作更精细的高保真交互原型。原型验证后的指标设计和迭代分析，则可与我的 Python、SQL 和机器学习能力结合，形成“需求发现—原型验证—研发交付—数据监控—持续优化”的完整产品闭环。
